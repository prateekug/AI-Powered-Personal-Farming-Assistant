⚙️ 2. How Each Part of the Backend Works

🚀 backend/app.py — Central Controller

Starts the Flask server on Port 5000, enables CORS security headers (allowing port 8000 to talk to port 5000), connects SQLite database, and registers all API blueprints.

🛡️ routes/auth.py — Login & Password Security

Register: Scrambles (hashes) user passwords using generate_password_hash() so passwords are never stored in plain text.
Login: Verifies password hash and issues a digitally signed JWT Token (like a digital VIP pass) stored in browser localStorage.

🚜 routes/farm.py — Land & Soil Profile Manager

Saves land size, soil pH, previous crop, and planting date into SQLite. Features GET /api/farm/profile which returns the complete aggregated profile for confirmation.html summary cards.

🧠 services/disease_service.py — AI Leaf Scanner

  • DiseasePredictionService (Pure ML): Preprocesses uploaded image (RGB -> resize 160x160 -> normalize pixels by dividing by 255.0) matching the notebook math, passes it to MobileNetV2, and outputs predicted disease and confidence %.
  • DiseaseInformationService (Advisory): Matches the predicted disease to farming advice (impact, treatments, prevention tips).

🎓 3. Essential Viva / Interview Questions

Q1: What is a REST API?

A REST API (Representational State Transfer) is an architectural style for web applications to exchange data using standard HTTP methods (GET, POST) and JSON format.

Q2: What is the difference between GET and POST?

GET retrieves data from the server without modifying anything (e.g. GET /api/farm/profile). POST sends new data to create/update records or run computations (e.g. POST /api/auth/login).

Q3: How do you secure user passwords?

Passwords are never saved in plain text. We use PBKDF2 SHA-256 one-way cryptographic hashing (Werkzeug). Even if someone accesses the database, they cannot read the original password.

Q4: How does JWT Authentication work?

Upon login, the server signs a token containing the user_id. The browser saves it in localStorage and sends it in the HTTP header Authorization: Bearer <token> for all protected requests.

Q5: What is CORS?

Cross-Origin Resource Sharing. Browsers block frontend JS on port 8000 from accessing backend port 5000 due to Same-Origin Policy. flask-cors sends headers allowing safe cross-port requests.

Q6: What is an ORM?

Object-Relational Mapping (SQLAlchemy). It lets us interact with database tables using Python classes (User, Farm, SoilData) instead of writing raw SQL strings, preventing SQL Injection attacks.

📊 4. HTTP Status Codes Quick Reference

Status Code Meaning Where Used in FarmAI
200 OK Success Login, fetching farm profile, leaf disease prediction.
201 Created Resource Created User registration.
400 Bad Request Client Input Error Invalid email, missing required form fields, invalid soil pH.
401 Unauthorized Auth Failure Wrong password, missing JWT token, or expired token.
